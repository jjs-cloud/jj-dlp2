## Quick Start Guide:
  
Step 1:  Click on the latest release in the right sidebar, then download the file for your platform.

Step 2:  Extract the archive, and double click on jj-dlp.exe (or jj-dlp on linux/mac) to run it. 

Step 3:  When you see the jj-dlp dashboard, you can add your favorite streamers to start monitoring for livestreams.

That's it!  Your streamers will be recorded automatically.

# jj-dlp v2 

jj-dlp is a app (built with Rust) that allows you to automatically record live streams, and automatically download short-form video posts, powered by [yt-dlp](https://github.com/yt-dlp/yt-dlp). 

---

## Features

- **Livestreams** — Monitor and record livestreams for several popular sites 
- **Posts** — Monitor and auto-download video posts for several popular sites 
- **Mobile notifications** — Get notifications on your phone/device when a recording starts
- **Schedule recordings** — record a stream only on a specific day or a specific time
- **Split recordings** — automatically split recordings into the duration of your choosing, without the need to wait until the end of the stream
- **Stall detection** — Alerts you if the download stalls 
- **Restart detection** — Alerts you if the download restarts 
- **Error detection** — Alerts you if errors are detected in the ffmpeg output
- **Twitch ad detection** — Alerts you if Twitch ads are detected in the recording
- **Output monitoring** — allows you to see the raw yt-dlp and ffmpeg command output, and log to a file.

## Dependencies 

- [ffmpeg](https://www.ffmpeg.org/) (jj-dlp will help you install ffmpeg if it's missing)
